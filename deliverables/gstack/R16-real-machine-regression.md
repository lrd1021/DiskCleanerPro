# R16 — 真机交互回归手册（DiskCleaner Pro）

> **目的**：R1–R14、R12 已通过代码审计 + 无头冒烟测试闭环；R16 要求在**带管理员权限的真实 Windows 机器**上做交互回归，验证 UAC 提权、Authenticode、回收站/永久删除等**依赖真实桌面会话**的行为。这些无法在 CI / 沙箱中完成，需人工按本手册点一遍（约 10–15 分钟）。

---

## 0. 前置条件

- Windows 10/11 物理机或虚拟机（**非**沙箱）。
- 一个**标准用户**账户（默认非管理员）+ 该账户要有**管理员 UAC 提权能力**（即属于 Administrators 组但平时以标准令牌运行）。
- 已拿到发布包 `publish/`（自包含，无需另行安装 .NET 8）。
- 准备一个**测试用**垃圾文件：`C:\Windows\Temp\dc_r16_test.txt`（随便写一行），用于步骤 2。

---

## 1. 无头冒烟（已自动化，先跑一遍确认基线）

```powershell
cd publish\..
# 用 .NET 8 SDK 直接跑冒烟工程（不需要管理员）
dotnet run --project src\DiskCleaner.SmokeTest --configuration Release
# 退出码 0 = 全部通过；非 0 = 有失败项，见输出
```

涵盖：目录树正确性、深 2000 层不爆栈、交接点守卫、重复检测、MsiExec 白名单、Elevated helper 守卫（本地路径/受保护根/MsiExec）。

---

## 2. 启动方式校验（asInvoker）

| 操作 | 预期 | 判定 |
|---|---|---|
| 双击 `publish\DiskCleanerPro.exe`（**不要**“以管理员身份运行”） | 界面正常加载，**启动时不弹 UAC** | ✅ 说明 `app.manifest` 为 `asInvoker`，未要求全程管理员 |

---

## 3. 受保护目录删除 → 触发 UAC（核心安全路径）

| 操作 | 预期 | 判定 |
|---|---|---|
| 在“临时文件清理”中，把清理目标指向 `C:\Windows\Temp\dc_r16_test.txt`，执行清理 | 弹出 **UAC 提权确认**（runas）；同意后文件被删除；**拒绝/取消**则文件保留、无任何静默永久删除 | ✅ 说明 `ElevationHelper.RunElevated("delete", …)` 正确拉起 `DiskCleaner.Elevated.exe` |
| 取消 UAC 后，确认 `dc_r16_test.txt` 仍在 | 文件存在 | ✅ 取消即中止，不删除 |

> 若取消 UAC 后文件消失 = ❌ 严重回归（静默永久删除），立即上报。

---

## 4. 回收站 vs 永久删除

| 操作 | 预期 | 判定 |
|---|---|---|
| 清理一个**普通用户目录**下的临时文件（如 `%TEMP%\dc_test.tmp`） | 文件进入**回收站**（可在回收站还原），而非永久消失 | ✅ `NativeMethods.SendToRecycleBin` 生效 |
| 清理**系统目录**中无法走回收站的文件 | 走 Elevated 删除且**有 UAC 提示**；回收站失败时**跳过**而非强制永久删 | ✅ 不出现“静默永久删除” |

---

## 5. 符号链接搬家（FileMover）

| 操作 | 预期 | 判定 |
|---|---|---|
| 用“文件搬家”把一个大文件夹从 C 盘移到 D 盘 | 流程为 复制 → 校验大小 → 删除源 → 建符号链接；若建链失败，源仍被正常移动（纯移动成功） | ✅ 不丢数据 |

---

## 6. 软件卸载安全确认

| 操作 | 预期 | 判定 |
|---|---|---|
| 卸载一个**受信任目录 + 有效数字签名**的程序（如系统组件） | 弹“以管理员权限运行 msiexec”确认框，**默认选“否”**；选“是”才执行 | ✅ `IsTrustworthyUninstaller` + 显式确认 |
| 卸载字符串为 `msiexec /i http://evil/x.msi` 的条目 | **提权前直接拒绝**，不弹 UAC、不启动任何进程 | ✅ `IsSafeMsiUninstall` 拦截（R1/R16 头less 已测，此处肉眼复核） |
| 卸载字符串指向 `\\server\share\app.exe` | 拒绝 | ✅ 拒绝 UNC |

---

## 7. 交接点 / 深目录健壮性

| 操作 | 预期 | 判定 |
|---|---|---|
| 创建一个指向自身的 junction（`mklink /J C:\test_loop C:\`），对 `C:\` 跑“磁盘分析” | 不无限循环、文件计数不翻倍、数秒内完成 | ✅ 交接点守卫 |
| 对 `node_modules` 这类深目录跑分析 | 不崩溃、不爆栈 | ✅ 迭代式后序遍历 |

---

## 8. Authenticode（沙箱无法验证，真机复核）

| 操作 | 预期 | 判定 |
|---|---|---|
| 卸载一个**系统签名程序**（如 `C:\Windows\System32` 下的已签名组件） | 通过签名校验，允许卸载流程 | ✅ 沙箱中 `IsAuthenticodeSigned` 因缺证书链返回 false，真机应返回 true |

---

## 通过标准

- 步骤 2–8 全部 ✅，且无任何“取消 UAC 后仍被删除 / 静默永久删除 / 未签名程序被放行”现象 → **R16 通过**。
- 任一 ❌ → 记录现象 + 截图，回到对应模块修复后重测。
